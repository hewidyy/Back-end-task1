# Back-end Task 1

A Node.js terminal program for adding, viewing and deleting 10 people's details. Each person has an ID, first name, last name, age and city.

Run:

```bash
node app.js
```

The data is saved in `data10.json`. Option 1 lets you replace the 10 sample people with your own input. Other options show all people, find someone by ID, delete all or one person, and display full names with cities.
